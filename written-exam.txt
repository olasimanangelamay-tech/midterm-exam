1. What is the primary operational difference between fit fetch and git pull? 
answer: git fetch downloads remote changes without applying them to your code. while git pull downloads and automatically merges those changes into your curent branch.

2. You have uncommitted changes in your working directory and need to temporarily switch to another branch. 
Which workflow prevents Git from bloking the checkoout due to file overwrites? 
answer: git stash

3.When executing a git merge--no-ff command, what specific behavior is enforced by Git? 
answer: it forces git to create a dedicated merge commit, even if it could merge automatically without  one, keeping feature history visible.

4. What happens when you check outt a specific commit hash directly (e.g., git checkout a1b2c3d) instead of a branch names? 
answer: puts git into a detached HEAD state where changes arent attached to a branch.

5. you need to apply a specific bug-fix commit from a development branch onto a stable release branch without merging 
the entire branch history. which command should you use? 
answer: git cherry-pick <commit-hash>

 which utility can retrieve these dangling commits?
